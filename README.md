# ปฏิทินบันทึกคำร้อง

หน้า GitHub Pages สำหรับเปิดเว็บปฏิทินบันทึกคำร้อง e-Filing / CIOS บนคอมพิวเตอร์และมือถือ

ข้อมูลและการตรวจรหัสยังอยู่ใน Google Apps Script และ Google Sheet ของเจ้าของระบบ หน้านี้เป็นเพียงทางเข้าเว็บ ไม่เก็บข้อมูลคดีหรือรหัสผ่าน และไม่รวมโค้ดส่วนฐานข้อมูลในคลังสาธารณะ

หากหน้าเว็บไม่แสดง ให้กด **เปิดหน้าเว็บโดยตรง** และลงชื่อเข้าใช้บัญชี Google เจ้าของระบบเพียงบัญชีเดียว
